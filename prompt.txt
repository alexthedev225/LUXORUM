## 🛠 Stack Technique Imposé

### UI Primitives & Composants
- **Radix UI** (@radix-ui/react-*) pour l'accessibilité
- **Lucide React** pour les icônes
- **Framer Motion** pour les animations avancées
- **tailwindcss-animate** pour les animations CSS

### Fonctionnalités
- **React Hook Form** pour les formulaires
- **clsx** + **tailwind-merge** pour la gestion des classes
- **react-hot-toast** ou **sonner** pour les notifications
- **chart.js** + **react-chartjs-2** pour les graphiques

### Framework
- **Next.js 14+**, **React 18+**, **Tailwind CSS 4+**

## ✅ Missions Précises

### 🎯 Objectifs de Refonte
1. **Styliser** la sidebar, header, menu mobile et contenu principal
2. **Respecter scrupuleusement** la palette de couleurs luxe
3. **Ajouter** des animations et transitions fluides (menu, hover, clic, focus)
4. **Garantir** une expérience fluide, haut de gamme, responsive et intuitive
5. **Créer** des micro-interactions élégantes (lueurs dorées, dégradés subtils, textures overlay)
6. **Veiller** à l'accessibilité et lisibilité optimale
7. **Appliquer** les principes UX avancés pour un design cohérent

### 🎨 Directives Esthétiques
- **Animations fluides** : Utilise Framer Motion pour les transitions complexes
- **Micro-interactions** : Hover effects avec lueurs dorées subtiles
- **Textures** : Overlays en pointillés et dégradés pour la profondeur
- **Espacement** : Lettres espacées pour les catégories (`tracking-[0.3em]`)
- **Accessibilité** : Contraste optimal, focus visible, navigation clavier

### 🔧 Optimisations Techniques
- **Performance** : Lazy loading, animations optimisées
- **Responsive** : Mobile-first, breakpoints fluides
- **Accessibilité** : ARIA labels, semantic HTML, keyboard navigation
- **UX** : Feedback immédiat, états de chargement, erreurs élégantes
